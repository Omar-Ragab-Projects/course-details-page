# Course Page

A minimal course-details page built for a learning platform.  
The page is designed to be clean, responsive, and easy to extend.

## ✨ Features

### 🎬 Wide Video Player
- Displays lecture videos in a wide, distraction-free layout.
- Mobile-responsive and scales down gracefully for smaller screens.

### 📱 Fully Responsive UI
- Adapts to phones, tablets, and desktops.
- Layout rearranges for readability and better user experience on any device.

### ❓ Module-Based Questions  
Each module includes a set of questions for learners to practice:
- Step-by-step question flow  
- Timed questions (auto-submit or lock when timeout is reached)  
- Feedback after each step  
- Can be adapted to quizzes or assessments

### 📄 PDF Topic Reader  
- PDF reading support inside the course topic section  
- Let students open and read module topics directly without leaving the page  
- Useful for handouts, slides, or text-based lessons

## 📂 What’s on the Course Details Page

- Course title, instructor, duration  
- Number of lessons & students  
- Language and level  
- Module list  
- Questions for each module  
- PDF topic viewer  
- Reviews & comments  

## 🛠️ Running the Project Locally

```bash
# Clone the repository
git clone <repo-url>

# Install dependencies
npm install

# Start development server
npm run dev
```
